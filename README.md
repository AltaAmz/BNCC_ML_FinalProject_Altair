## Overview

The model estimates an individual's obesity level (`NObeyesdad`) — one of **7 ordered
categories** from *Insufficient Weight* to *Obesity Type III* — using:

- Anthropometric data: age, height, weight
- Eating habits: meal frequency, vegetable intake, snacking, high-calorie food consumption
- Lifestyle factors: physical activity, water intake, smoking, alcohol use, screen time,
  transportation mode

Three classifiers (KNN, Random Forest, Gradient Boosting) were trained, cross-validated,
and tuned with `GridSearchCV`. The best model — a **tuned Random Forest** — was exported
and wrapped in a Streamlit app for interactive predictions.

## Dataset

- File: `estimation_of_obesity_levels_based_on_habits.csv.csv`
- 17 columns: 16 features + 1 target (`NObeyesdad`)
- ~211 rows contained missing values, which were imputed (mean for numeric columns,
  most-frequent for categorical columns); rows missing the target label were dropped

| Feature | Type | Description |
|---|---|---|
| Gender | Categorical | Female / Male |
| Age | Numeric | Age in years |
| Height | Numeric | Height in meters |
| Weight | Numeric | Weight in kilograms |
| family_history_with_overweight | Categorical | Family history of overweight (yes/no) |
| FAVC | Categorical | Frequent high-caloric food consumption |
| FCVC | Numeric | Vegetable consumption frequency (0–3) |
| NCP | Numeric | Number of main meals per day |
| CAEC | Ordinal | Eating between meals |
| SMOKE | Categorical | Smoking habit |
| CH2O | Numeric | Daily water consumption |
| SCC | Categorical | Monitors calorie intake |
| FAF | Numeric | Physical activity frequency |
| TUE | Numeric | Technology device usage time |
| CALC | Ordinal | Alcohol consumption |
| MTRANS | Categorical | Main transportation mode |
| **NObeyesdad** | **Target** | **Obesity level (7 classes)** |

## Pipeline Summary

1. **EDA** — class distribution, missing-value audit, correlation heatmap, meal-frequency
   vs. obesity-level boxplot.
2. **Cleaning** — drop rows with a missing label; impute remaining numeric columns
   (median) and categorical columns (most frequent) inside a `ColumnTransformer`.
3. **Preprocessing** — numeric scaling (`StandardScaler`), ordinal encoding for `CAEC`
   and `CALC`, one-hot encoding for nominal columns.
4. **Modeling** — baseline KNN, Random Forest, and Gradient Boosting; 5-fold stratified
   cross-validation; hyperparameter tuning via `GridSearchCV` optimizing macro F1.
5. **Evaluation** — accuracy, macro precision/recall/F1, full classification report,
   confusion matrix, and error analysis on the 20% held-out test set.
6. **Deployment** — best pipeline saved with `joblib`; a self-contained Streamlit app is
   generated for interactive predictions.

## Results

Best model: **Random Forest** (tuned)

| Metric | Score |
|---|---|
| Accuracy | 0.91 |
| Precision (macro) | 0.91 |
| Recall (macro) | 0.90 |
| F1-score (macro) | 0.90 |

The model performs strongly across all 7 classes (F1 ≥ 0.85 in most), with
`Normal_Weight` and `Overweight_Level_II` being the most frequently confused pair,
reflecting how closely they sit on the underlying weight/BMI spectrum. See
[`documentation.pdf`](./documentation.pdf) for the full classification report, confusion
matrix, and hyperparameter search details.

## Getting Started

### 1. Requirements

- Python 3.9+
- Jupyter Notebook / JupyterLab / Google Colab (to run the `.ipynb`)

### 2. Reproduce the Notebook

```bash
pip install pandas numpy matplotlib seaborn scikit-learn joblib
```

1. Place `estimation_of_obesity_levels_based_on_habits.csv.csv` in the same folder as
   the notebook.
2. Open `BNCC_FinalProject_Altair.ipynb` and run all cells top to bottom.
3. This regenerates `best_obesity_pipeline.joblib`, `app.py`, and `requirements.txt`.

### 3. Run the Streamlit App

```bash
pip install -r requirements.txt
streamlit run app.py
```

Make sure `best_obesity_pipeline.joblib` is in the same directory as `app.py` — the app
will show an error and stop if it can't find the model file.

The app opens a form to enter personal information, eating habits, and lifestyle data,
then returns the predicted obesity level along with the computed BMI for reference.

## App Preview

The Streamlit app includes:

- 👤 **Personal Information** — gender, age, height, weight
- 🍽️ **Eating Habits** — family history, high-calorie food, vegetables, meals/day,
  snacking, alcohol
- 🏃 **Lifestyle** — smoking, water intake, calorie monitoring, physical activity,
  screen time, transportation
- 📊 **Prediction Result** — predicted obesity class, BMI, and the raw input data for

> **Academic Project Disclaimer:** This application is built for machine learning
> project demonstration purposes. Its predictions are not a medical diagnosis and
> should not replace professional medical advice.

## Limitations

- The dataset is self-reported survey data; several features (FCVC, NCP, FAF, etc.) use
  coarse numeric scales rather than precise measurements.
- ~211 rows required imputation, which can smooth over some natural variance.
- `Normal_Weight` and `Overweight_Level_II` are the classes most often confused with
  each other.
- Not validated for clinical or medical use.
